# 采购智能体防扰动设计

当前智能体增加了轻量 guardrail，代码在 `guardrails.py`。

主要拦截：

- 用户要求忽略系统规则、覆盖提示词、切换角色。
- 用户要求输出系统提示词、内部指令、密钥、token、数据库密码等敏感信息。
- 用户要求删除数据库、执行 SQL、运行 Shell 或脚本等越权操作。

命中后不会调用任何业务 tool，也不会进入大模型自由推理，而是直接返回边界说明。

面试表达：

> 我没有只依赖 prompt 做安全约束，而是在模型调用前增加了一层代码级 guardrail。对于提示词注入、角色劫持、敏感信息请求和越权写操作，系统会先拦截并返回安全边界说明；只有正常采购问题才会进入工具查询和模型总结流程。
