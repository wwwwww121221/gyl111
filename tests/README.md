# 采购智能体流程分流测试

本目录用于验证 `procurement_agent` 的流程模式分流逻辑。

## 运行方式

```bash
python -m unittest tests.test_procurement_agent_flow_mode -v
```

## 测试场景

| 编号 | flow_mode | 用户输入 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 空 | 查一下这个物料历史价格 | 直接返回历史价格，不要求选择流程 |
| 2 | auto_inquiry | 先查一下历史价格 | 只查询历史价格，不创建询价单 |
| 3 | 空 | 帮我发起询价 | 返回选择卡片，让用户选择自动询价或手动比价 |
| 4 | auto_inquiry | 把勾选物料发起询价 | 生成自动询价确认卡片，确认后发送给供应商 |
| 5 | manual_compare | 根据报价分配份额并生成合同 | 不发送询价单，生成比价和份额分配确认卡片 |
